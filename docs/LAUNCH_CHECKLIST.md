# Launch checklist

## Prototype gate

- [x] Strict TypeScript, lint, tests, and optimized build pass.
- [x] Sample commerce content is clearly disclosed.
- [x] Payment and return simulations make clear that no real transaction occurs.
- [x] Metadata, robots, sitemap, and not-found behavior exist.
- [x] Product and service routes have implemented or explicit deferred states.
- [x] Automated Chrome desktop/mobile-emulation checks and selected axe audits exist.
- [ ] Complete manual screen-reader, real-device and cross-engine testing; automated checks are not full conformance evidence.
- [ ] Replace sample content, policies and media; remove demo noindex only after launch approval.

## Production blockers

- [ ] Confirm legal entity, domain, target markets, currency, tax, duties, and restricted shipping.
- [ ] Complete trademark clearance and replace concept media with licensed assets.
- [ ] Connect authoritative catalog, pricing, inventory, checkout, order, returns, customer, CMS, email, store, and support adapters.
- [ ] Complete legal, privacy, accessibility, penetration, and payment-provider reviews.
- [ ] Configure consent, telemetry redaction, monitoring, SLOs, alert routing, on-call ownership, and synthetic checks.
- [ ] Test webhooks, idempotency, replay handling, provider outages, inventory conflicts, refunds, and reconciliation.
- [ ] Record launch approvers, incident channel, rollback owner, success metrics, and first-week review schedule.
